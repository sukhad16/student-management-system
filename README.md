Student Management System

A Little About the Project

A simple Python project for maintaining basic student records.

The program helps users add, view, search, update or delete student information. It also calculates grade based on the given marks.

Features

To add student

To display all students

To search student using ID

To update student information

To remove student

To calculate grade automatically

To store the data in JSON file

Technologies Used

Variables

Input and Output

If-else statements

For and while loops

Functions

Array

Dictionaries

File handling

Basic exception handling

Running Instructions

Install Python 3.

Open this folder in VS Code.

Open the terminal and run:

python main.py

Files

main.py – main program

students.json – holds the records of students

README.md – information about the project
